# SnapDoc

Android document scanner: scan with the camera or import from the gallery, auto-detect and crop the page, enhance it, annotate it, and export a PDF.

## Features
- Camera scan with automatic edge detection, manual corner adjustment, batch mode
- Import one or many images from the gallery
- Filters (Original, Enhanced, Gray, B&W), brightness, contrast, shadow removal
- Crop, rotate, draw / highlight, add text, add a saved signature
- Multi-page documents: reorder, delete, rename, search
- PDF export (A4 or fit to image), save to Downloads, share as PDF or images
- Offline text extraction (OCR) for Arabic and English
- Merge documents

## Build
The APK is built by GitHub Actions on every push to `main` and published under **Releases**.
